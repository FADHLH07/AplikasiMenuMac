APLIKASI MENU - Pemrograman Visual (C# + Avalonia, jalan di Mac)

1. Install .NET 8 SDK:
   - Download dari https://dotnet.microsoft.com/download  (pilih macOS Arm64 untuk M1/M2/M3/M4, x64 untuk Mac Intel)
   - atau lewat Homebrew:  brew install --cask dotnet-sdk
   Cek dengan:  dotnet --version

2. Buka folder ini di VS Code (File > Open Folder). Disarankan install extension "C# Dev Kit".

3. Di terminal VS Code (Ctrl + `) ketik:
       dotnet run
   Pertama kali butuh internet buat download paket Avalonia.

4. Edit data diri di Forms.cs -> cari "class FormAbout".
